konsep halaman Action Plan supaya bukan seperti LMS yang menampilkan daftar materi panjang seperti screenshot referensi, tetapi menjadi personal weekly planner yang sangat jelas: siswa memilih fokus → ORBITA menyusun maksimal 5 aktivitas/hari → siswa bisa re-plan → klik tanggal untuk melihat aktivitas hari tersebut.

Menurut saya struktur terbaiknya seperti ini:

2. Bagian paling atas: Fokus Belajar Minggu Ini

Ini harus menjadi bagian yang sangat jelas karena ini adalah input utama sistem.

🎯 Fokus Belajar Minggu Ini

Pilih maksimal 2 fokus. ORBITA akan menyesuaikan aktivitasmu berdasarkan fokus pilihanmu.

Kemudian:

┌───────────────┐  ┌───────────────┐  ┌───────────────┐
│ 📝 SNBT       │  │ 🎯 TKA        │  │ 🏛️ Kedinasan │
│               │  │               │  │               │
│ Progress 58%  │  │ Progress 42%  │  │ Progress 31%  │
│ ✓ Dipilih     │  │ ✓ Dipilih     │  │ Pilih         │
└───────────────┘  └───────────────┘  └───────────────┘

                  [↻ Re-plan]

Kalau siswa memilih SNBT + TKA, maka ORBITA memahami:

Minggu ini prioritas siswa = SNBT + TKA.

Dan sistem menyusun aktivitas berdasarkan dua fokus tersebut.

Microcopy yang lebih Gen Z:

Mau fokus ke mana minggu ini? 👀
Pilih maksimal 2 biar belajarnya lebih terarah.

Ini lebih ringan daripada:

"Pilih maksimal 2 fokus belajar untuk minggu ini."

6. Maksimal 5 To-do itu bagus, pertahankan

Menurut saya 5 adalah batas yang tepat.

Tapi jangan berarti sistem harus selalu mengisi 5.

Misalnya hari itu sebenarnya hanya membutuhkan 3 aktivitas:

Today's Mission
3 aktivitas

Latihan Penalaran
Review Literasi
Mini Tryout

Jangan menambahkan aktivitas random hanya untuk mencapai angka 5.

Jadi:

Maximum 5, not always 5.

Ini penting untuk menghindari siswa merasa:

"Buset, banyak banget."

7. Bedakan aktivitas ORBITA dan aktivitas buatan siswa

Karena kamu sebelumnya ingin ada "Buat Aktivitas", saya sarankan aktivitas buatan siswa memiliki style sedikit berbeda.

Contoh:

Dengan begitu siswa tahu:

"Ini rekomendasi sistem."

vs.

"Ini agenda yang aku buat sendiri."

8. Tambahkan "Aktivitas belum selesai"

Ini juga penting karena sebelumnya kamu ingin Action Plan hari berikutnya tidak bisa dilihat sebelum hari ini selesai.

Saya justru akan membuat mekanismenya seperti:

⚠️ Masih ada yang belum selesai

Kamu masih punya 1 aktivitas dari kemarin.

Review Pembahasan Literasi

[Lanjutkan] [Lewati]

Baru setelah itu aktivitas hari ini.

Tetapi saya tidak akan memblokir seluruh kalender. Siswa tetap boleh melihat kalender, tetapi aktivitas masa depan tidak bisa dimulai kalau ada aktivitas wajib yang belum selesai.

Jadi:

View ≠ Access

Mereka boleh melihat besok, tetapi tidak bisa mengerjakan/menjalankan Action Plan besok sebelum hari ini selesai.
