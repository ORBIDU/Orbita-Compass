# Referensi desain portal siswa ORBIDU

File .dc.html di folder ini adalah file desain dari canvas, bukan kode aplikasi. Dibuka hanya sebagai acuan tampilan; tidak ikut di-build.

- PortalHeader.dc.html         : Komponen header portal desktop.
- Portal-Dashboard.dc.html     : Dashboard desktop, tiga status siswa (baru, sudah_asesmen, aktif).
- Portal-Dashboard-HP.dc.html  : Dashboard versi HP dengan menu bawah 5 item.
- Portal-Analisis.dc.html      : Analisis Potensi desktop, tab Gambaran Minat Bakat, Prestasi, Nilai Rapor.
- Portal-Analisis-HP.dc.html   : Analisis Potensi versi HP (lebar 390).
- Portal-Compass.dc.html       : ORBIDU Compass desktop. Mode Demo: Terkunci dan Terbuka.
- Portal-Beasiswa.dc.html      : Explore Beasiswa desktop (filter, simpan, jendela detail). Data beasiswa masih contoh.
- Portal-ActionPlan.dc.html    : Action Plan desktop. Semua tugas berupa latihan soal dari AI per hari belajar. Kalender sticky di laptop. Mode Demo: Terkunci, Belum ada rencana, Aktif.
- Portal-SiapSNBP.dc.html      : Siap SNBP desktop, rasionalisasi 3 langkah (Input data, Review, Hasil). Tweaks: langkah, raporKosong. Hasil berupa kategori Aman, Waspada, Berisiko, bukan persentase.
- Portal-SiapUjian.dc.html     : Satu template untuk Siap SNBT, TKA, SKD dengan tab Latihan Soal, Tryout, Performance. Panel 'Contoh ujian' mengganti isi per ujian.
- Portal-Pengerjaan.dc.html    : Halaman pengerjaan soal tanpa menu portal. Panel 'Contoh mode': Latihan (pembahasan langsung setelah cek jawaban) dan Tryout (timer per subtes, ragu-ragu, konfirmasi selesai).
- Portal-Laporan.dc.html       : Laporan tryout: skor dan kenaikan, hasil per subtes, fokus berikutnya, pembahasan dengan filter Salah, Ragu-ragu, Tidak dijawab.

- Portal-Profil.dc.html       : Profil desktop. Data diri dari pihak kurikulum sekolah, hanya bisa dibaca; siswa hanya mengubah nama panggilan, foto, dan password. Kondisi keluarga dan khusus disembunyikan default. Panel 'Data sekolah': Lengkap, Sebagian, Belum diisi.

Contoh soal di desain hanya ilustrasi. Bank soal asli menunggu tim data.
